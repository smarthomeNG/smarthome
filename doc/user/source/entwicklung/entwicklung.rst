Entwicklung :bluesup:`Update`
=============================

Hier entsteht nach und nach der Teil der Dokumentation, welcher sich mit der Entwicklung von SmartHomeNG befasst.

Welche Teile von SmartHomeNG als stabile Schnittstelle gelten und wie Versionsnummern vergeben werden,
ist unter :doc:`Öffentliche API und Versionierung <public_api>` beschrieben. Das gilt für alle, die auf
SmartHomeNG aufbauen: Plugins, Module, Logiken und Visualisierungen.
